# Rule 1 - 方向比較必須有可審閱的內容證據

- 必須先從固定 `style-library/catalog.json` 的可選項，按內容關係篩選解說形式與藝術表現；讀相應原始卡、實作及可播放預覽，記錄庫內 ID、目錄 SHA、適配與捨棄理由。7 種可用解說形式與 35 種藝術示範是不同維度，不是 43 個同等成熟的成片模板；研究卡及不可選弱項不得混入正式候選。
- 庫內示範只能支持視覺比較，不能替代新素材、有配音與燒錄字幕的同內容代表片。從庫內規則改編構圖、動態與素材，禁止只替換配色；禁止搬用上游保留權利的角色或將其畫風名稱當成新素材已完成的證據。
- 需要庫外新風格時，先在獨立擴充工作加入合法來源、穩定 ID、實作與實際預覽，通過風格庫檢查後才選用；沒有擴充授權時先完成現有庫內候選，具體說明缺口，不把搜尋結果冒充已整合。已有真人確認的舊方向可沿用，記錄歷史來源，不偽造對應庫內 ID；新片仍須完成本片適配與選用檢查；選用 JSON 可用互斥的 reuse 模式，攜帶選用檔目錄內的 evidence 路徑、sha256 與 adaptation，工具核對確認證據實檔。
- 必須從理解目標、內容關係、觀眾與觀看情境、品牌限制推導候選方向；色相無來源依據時必須標為美術裁量，不得杜撰色彩心理或唯一正解。
- 未定方向時，AI 必須主動從上述來源形成至少兩個候選，先提出推薦初選並實作同一代表內容的候選預覽，再依實際畫面與成片評審修正最終推薦；至少兩個候選都必須以實質不同的實際畫面、有聲片段與跨幕縮圖證明各自的美術選擇。
- 候選比較必須依內容需要檢查具體視覺語言與內容關係，例如插畫／實物／圖解選擇、構圖與文字層級、材質／空間、動態語言、色彩、焦點與節奏；適用項目由內容決定，不得要求每片把所有項目都換過。
- 只有色彩、卡片位置或動線改變時，不足以證明完成美術探索；必須明列證據不足並補上能實際檢驗美術選擇的候選製作。色彩效果比較應控制其他條件；無法控制時必須限制歸因。
- 代表片段必須是含配音與燒錄字幕的實際編碼影片，具備該段獨立契約，完成與正式片相同的技術守門及成片評審才可稱為「已通過代表段」；具體判準依本 Skill 成片評審規範，能力限制另記。
- 必須先檢視實際預覽、測試推薦可能失敗的情境，再記錄推薦、取捨與未呈現項目；關鍵動態不得用色票或靜態淡化冒充。
- 已有方向時，只有在確認來源、版本與適用範圍可追溯時才可沿用；新主題必須說明本片適配理由，不得以 AI 推定或測試預設代替真人確認，深色方案不是通用預設。

## Good Example

實際候選、成片觀察與來源記錄共同支持推薦，且差異依內容需要呈現。

### Example 1

AI 依活動報名審核內容、首次報名者與理解目標提出「流程圖解」與「具象審核場景」，先把「具象審核場景」列為推薦初選，實作兩個同一段含配音、燒錄字幕與跨幕縮圖的實際編碼預覽；檢視畫面後發現流程圖解更清楚呈現審核步驟關係，便把最終推薦改為流程圖解，並記錄兩案取捨與預覽位置。

### Example 2

已完成有實質美術差異的候選後，若內容只需要追加比較配色，才在相同構圖與動態條件下比較兩套色系，分開記錄色彩觀察與結構決策；不把配色子比較當成整體美術探索，內容需要材質或空間差異時才實作相應候選，不要求每片更換全部視覺項目。

## Bad Example

在沒有實片證據、來源追溯或真人確認時，把空白選項、單一換位或測試預設寫成方向結論。

### Example 1

需求尚未提供美術術語，就先留空候選並要求使用者選擇風格，沒有從內容、觀眾與理解目標主動形成候選。

### Example 2

同一張卡片只換顏色、位置或移動路線，就宣稱完成風格探索，沒有實作能證明不同美術語言與內容關係的候選。

### Example 3

測試回覆預設植物影片使用淺綠，卻把它記成真人已確認的方向，或把 AI 推定的偏好當成使用者確認。

# Rule 2 - 每個動作必須服務理解

- 必須讓交棒、拆分、形變、回接與鏡頭移動對應內容中的責任移轉、組成、變化、關係或細節；不得只輪流變色或裝飾移動。
- 每個敘事節拍必須先定一個核心訊息、對應旁白詞與主要觀看對象；畫面層級必須讓觀眾能指出當下重點，不得讓所有項目以同等強度輪播代替敘事。
- 必須依內容關係、實際語音與閱讀量安排動靜：需要動作時以動作帶入關係，再以落定姿態強調核心，保留穩定理解區間後才轉場；穩定區間必須寫明看什麼及時間依據，不得把移動拉滿整句後硬切，或用每幕同一時長的套版節奏。
- 核心落定強調期間，其他元素必須維持靜止或降低視覺層級，不得以同時的大幅移動搶走主焦點。
- 可以刪除分散注意力的動作、整段保持靜止，或因語意需要連續運動；連續運動必須說明觀眾追蹤哪個核心與可辨識狀態，不得把四段固定動畫順序當成每幕必做清單。
- 必須讓切點落在動作收束與訊息交接處；有意跨幕延續動作時必須保持物件身份、空間方向與運動脈絡，並記錄理由；不得無理由截斷尚未到位的重點。解說未完時必須保留觀看對象與必要脈絡。
- 必須選擇能驗證內容關係、閱讀負荷與動作的代表段落，必須以實際代表片段檢驗所選內容關係、動作與閱讀負荷；已有方向時可以沿用方向，不得因舊片曾選某幕就固定照用。

## Good Example

動作與停留都有可辨識的觀看對象及理解目的。

1. 通知從系統交給借閱者，接收者被強調；鏡頭再推近到期日，解釋提醒時機。
2. 旁白說到「到期日」前鏡頭到位，日期保持穩定供閱讀，再以通知發出作下一幕交接；沒有必要時整幕只做日期對照。

## Bad Example

畫面失去當下解說對象，或動作沒有內容目的。

1. 旁白仍說到期日，焦點已離開，畫面僅等下一幕。
2. 手指整句一直移動，尚未到土壤重點就切到下一幕；或每幕同樣滑入、同樣停半秒，不考慮句意與閱讀量。

# Rule 3 - 旁白契約必須獨立且逐項完整

- 必須先從內容與實際語音時間制定期望，再實作動畫；焦點契約必須獨立於繪圖 active，不能把程式當下亮什麼反推成正確答案。
- 必須覆蓋全片每段解說的完整起訖，列舉必須逐項對應具名物件與辨識文字，不能只亮群組。
- 應覆蓋完整解說；需要進場或交棒容許時必須逐段說明實際動作理由，並指定豁免過渡的成片取樣，不能沿用上一片固定寬限。
- 必須讀取工具產生的最終 timeline 與實際旁白時間，從實際切點倒推動作結束及穩定理解區間；不得以估計的幕長代替最終編碼時間。
- 必須以實際旁白時間核對動作、閱讀與交接，未講完不得提前移走主焦點；短句必須檢查其中途與尾端。

## Good Example

每項解說有獨立的對象與時間，例外另看成片。

1. 「到期日、借閱人」分成兩個獨立期望物件，兩者依語音各自持續聚焦。
2. 交棒進場有明確目的，另看該豁免時段實際成片。

## Bad Example

用群組代替列舉，或讓動畫自己產生正確答案。

1. 說了兩項卻只要求整張卡亮起。
2. 把 exporter 的 active 複製到期望表，所以錯焦點也能通過。

# Rule 4 - 移動過程必須保留可讀身份

- 必須讓移動、拆分與形變中的物件持續帶著可辨識名稱；不得等落地後才補字。
- 必須設計避開文字的傳遞路徑，鏡頭必須保留當前重點與必要脈絡；名稱、字幕與主要內容必須在實際大小下可讀。
- 必須預留字幕區並檢查文字長度、對比及遮擋；狀態可見或邊界合格不得替代實際畫格的可讀性判斷。

## Good Example

身份隨動作保留，路徑、字幕與鏡頭維持可讀性。

1. 借閱單形變成通知時名稱隨物件移動，路徑繞開收件人文字。
2. 推近到期日後仍保留借閱對象，字幕在獨立下方區域。

## Bad Example

移動中失去名稱，或以程式可見代替實際可讀。

1. 形變中只有空白色塊，落地後才出現通知名稱。
2. 框仍在畫內但連線壓住文字，卻以狀態檢查通過當作可讀。
