# Rule 1 - 評審對象必須是實際編碼成片

- 必須檢查實際編碼 MP4，涵蓋全片各段解說中途、尾端、移動／形變／交棒／鏡頭過渡與所有豁免區間；週期抽幀不足時必須補語意風險時間點。
- 必須核對名稱、路徑、鏡頭、字幕、來源內容、焦點與停留目的；只看原稿、Studio 或物件落地畫面不能通過成片評審。
- 必須以實際編碼成片的時間／畫格／位置對照已選方向的辨識特徵與內容目的，記錄實片證據及對理解的作用；不得只用 brief、storyboard 或單張示意代替。
- 發現成片退回統一卡片套版或偏離推薦方向時，必須定位受影響的成片時間與畫格，提出修正並重新複查。
- 必須從編碼成片逐幀擷取每個切點前後的連續序列，範圍必須涵蓋動作收尾、核心穩定期與下一幕進場；高風險移動必須另涵蓋其起迄，逐項記下位置／方向變化、身份、落定、穩定閱讀時間及切換理由。孤立畫格、技術通過或自報動作時長不得代替序列觀察。
- 必須記錄主要物件的逐幀位置變化、實際落定幀、穩定區間及時長；以狀態資料輔助時必須與編碼序列交叉核對，不得只寫「看起來可以」。
- 必須將序列觀察與實際語音時間對照，核對核心是否在對應詞句得到強調；只有逐幀圖像與時間資料時，必須限制為可觀察的切斷、跳位、可讀性及落定證據，不得宣稱已驗證連續聽感、動態舒適度或現場簡報效果。
- 必須從成片畫格確認字幕已燒錄且不遮內容；沒有字幕軌不能單獨證明字幕已燒錄。

## Good Example

以實際 MP4 的位置與連續畫格同時對照已選方向的特徵及內容目的。

### Example 1

已選「實物拆解」方向時，MP4 4.2–6.8 秒的連續畫格仍呈現材料、空間與拆解關係，且在旁白說明步驟時保留對應物件；評審記下該位置與方向版本，並核對字幕與落定時間。

### Example 2

切點前後逐幀序列顯示核心已落定、主訊息保持到句末才換幕；同時發現下一段退回統一卡片套版，便定位該段時間與畫格，列為偏離推薦方向並退回修正。

## Bad Example

僅以技術狀態、原稿、落地畫面或孤立畫格推定已符合美術方向。

### Example 1

只看 Studio 的物件落地畫面或切點前後各一張 PNG，沒有以實片位置對照已選方向，也沒有檢查尚在移動就消失的中間過程，仍說方向與節奏通過。

### Example 2

MP4 解析度、字幕燒錄與狀態檢查都通過，但實片退回與推薦不同的統一卡片，仍因技術成功而宣稱美術品質完成。

# Rule 2 - 修正必須使來源與證據重新對齊

- 必須將問題定位到成片版本與時間，寫明可觀察現象、影響理解的原因、修法與複查觀察。
- 來源修改後必須重建並重新檢查受影響範圍及必要整體關聯；證據必須綁定新成片與來源，不得沿用舊抽幀冒充新片。
- 必須在交付前核對來源、成片、狀態與評審所指為同一版本；工具失敗時必須保留上一版並列明失敗。

## Good Example

修正後重新建置、取樣，並把觀察綁到新版本。

1. 5.2 秒標籤消失：修正透明度後重建，重新看 5.1、5.2、5.4 秒並綁新 MP4 SHA。
2. 字幕改動後重新輸出、抽幀及填寫新的評審版本。

## Bad Example

用舊影片或舊抽幀代表尚未驗證的修正。

1. 改了動畫，但評審仍引用舊影片的截圖。
2. 建置失敗後仍把舊正式片說成已包含本輪修正。

# Rule 3 - 各種檢查結果必須分別記錄

- 必須分別記錄自動技術與狀態檢查、靜態畫格評審、音訊分析、使用者驗收的結果與證據。
- 必須在美術評審記錄當前目錄 SHA、庫內選用 ID 或沿用證據、規範如何落在本片實際成片；缺少、過期或僅用原庫示範不能通過。
- 必須另外記錄美術方向符合性與內容理解適配的實片觀察及證據，至少指向已選方向版本、辨識特徵、成片位置／畫格與理解目的；不得把美術方向符合性併入技術或使用者驗收結果。
- 必須區分通過、不通過與未驗證；必須列出尚待真人判斷的範圍與版本，AI 推定與測試預設不能改寫成真人確認。
- 只有抽幀、靜態畫格、ASR 或音訊分析時，必須明示這些證據不能證明連續聽感、連續節奏或動態舒適度。
- 必須原樣保留使用者接受的範圍與版本；使用者接受不能改寫 AI 是否直接聽看的事實，也不得推定使用者觀看方式。

## Good Example

各種證據、美術適配觀察與真人判斷各自標示狀態，不把一種結果改寫成另一種結果。

### Example 1

技術及靜態畫格通過、音訊匹配完成；另記錄已選方向的實片特徵與理解適配觀察，使用者只接受指定版本的代表段，尚待真人判斷的範圍清楚列出。

### Example 2

只完成抽幀與 ASR 時，記錄可觀察的畫面位置、字幕與詞句對照，並標明抽幀不能證明連續聽感或動態舒適度。

## Bad Example

把不同證據合併成未經支持的美術或聽看結論。

### Example 1

使用者說 OK，便把抽幀結果寫成 AI 已完整聽看，並把使用者接受範圍擴大成整片美術方向已驗證。

### Example 2

抽幀與 ASR 全文正確，便宣稱已驗證連續聽感、聲畫節奏舒適或動態適配。

# Rule 4 - 交付必須明示缺陷與能力限制

- 必須先修正漏項、提前失焦、錯對象、名稱消失、裁切、字幕遮擋、動作被無理由切斷、核心未落定與過期證據等可修正缺陷，再交付正式入口。
- 發現已選美術方向的辨識特徵或內容目的在實際成片中有落差時，必須先定位、修正、重建並複查受影響範圍，再交付正式入口；技術檢查成功不得宣告美術品質完成。
- 限定測試、代表段或未含真人驗收的結案，必須明示輸入、影片／段落範圍、證據與尚待真人判斷項目；不得擴大宣稱整片或開放選風格能力已驗證。
- 只有能力不足而無已知缺陷時，可以依授權提供帶限制的交付；必須具體列未驗證事項、證據範圍及使用者尚需判斷項目，不得聲稱完整聽看通過。
- 必須交付同一成片的播放與下載入口、可修改字幕來源、重建來源及命令，並保留使用者驗收狀態；工具缺失、建置失敗或缺少必要素材時不得宣稱完成。

## Good Example

先修正方向落差與已知缺陷，再依實際證據交付並揭露範圍。

### Example 1

MP4 在 8.0 秒退回統一卡片，雖然 encode 與字幕檢查通過，仍先定位方向落差、修正並重建，複查同一時間及必要整體關聯後才交付。

### Example 2

S1 只驗證兩個候選代表段時，記明測試輸入、影片範圍與畫格證據，並列出尚未真人確認的整片方向與品質項目；不把該測試結案寫成開放選風格能力已通過。

## Bad Example

已知方向落差或測試範圍不足仍被標為完整完成。

### Example 1

已知成片偏離已選方向，仍因解析度、字幕與 encode 成功直接發布，將技術通過寫成美術品質完成。

### Example 2

只有植物測試預設與一段抽幀證據，卻宣稱整片與真人方向確認都已完成，沒有標示測試輸入、範圍及尚待真人判斷。
