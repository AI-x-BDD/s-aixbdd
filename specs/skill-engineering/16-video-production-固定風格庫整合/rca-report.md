# 根因與驗收條件

使用者反覆要求流程內建數量充足的風格庫，並明確要求實際搜尋、產物及 Claude 協助。前版 Phase 2 步驟 5 只委派一般設計 Skills；這些指引不是固定可選風格集合。規則要求 AI 形成兩案，卻沒有必要目錄、穩定 ID、可播放預覽與缺庫阻擋，因此產生 A/B 就可能通過，被誤報為已處理風格選擇。

問題屬 Skill 流程與必要依賴缺失，不是使用者不會下提示詞。之前的風格庫實測只在獨立證明目錄，未接進正式流程。此次直接補實作；授權依使用者既有「確認，開始執行」及最新「要做一些搜尋、做出成果讓我判斷」，不重設空白確認關卡。

驗收：固定來源與授權、42 個實際預覽與缺素材項目明示、可搜尋分類播放頁、選用 ID 與內容適配、來源／預覽／目錄過期阻擋、新設定預設啟用守門、舊片可重建、兩側同步、Claude 查核。數量代表庫覆蓋，不能聲稱所有風格已經通過新題材成片品質驗收。
