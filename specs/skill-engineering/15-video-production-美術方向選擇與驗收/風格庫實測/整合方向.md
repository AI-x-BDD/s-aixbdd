# 固定風格庫為必要依賴

使用者最新要求：video-production 必須事先具備數量充足、可預覽的固定風格庫，製作時依內容從庫中挑選，不能每次臨時搜尋或僅憑 agent 發想。

根因：原流程僅必須載入設計原則與動態指導，未要求固定風格目錄、可執行預覽與可追溯的選用項目，導致 A/B 被當作完成風格選擇能力。現行 Skill 在此點不符合使用者要求。

具體整合方向：將固定版本 huashu-art-motion 作為候選必要依賴，第三方原文與授權保持原樣；由專案維護自己的風格目錄，條目有來源、預覽、適用內容、限制、建置入口及驗證狀態。解說語法、藝術風格、配色分開，不能混算數量。研究配方不能當成熟可選項目。安裝與建庫在製作前完成，缺庫時指出缺依賴，不得退回臨時搜尋。每次製作由 agent 依內容篩選並實作候選，同內容比較後推薦使用者確認；方向已確認則沿用。

初次實測：已下載固定 revision、補齊隔離渲染環境，成功輸出原庫黑板範例（10秒300幀）與包浩斯範例（2秒60幀），皆1920×1080 H.264。已檢視實片抽幀。這證明兩個範例能執行，不等於全部風格驗證、正式影片品質通過或流程已整合。範例無配音與字幕，並非新交付影片。

狀態：候選工具實測完成；整合與完整風格庫建置尚未施工。此檔是可審查的修正方向，不是已完成宣告。其餘畫格、音訊與來源一致性守門保留。
