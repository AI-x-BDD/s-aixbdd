# 移除不支援能力的待驗證項目

使用者明確要求移除「AI 直接連續聽看尚未驗證」。根因是將當前未提供的輸入能力，建模為每次交付的未完成檢查，導致反覆回報為待辦。此明確修改指示即為本次範圍授權，不另開確認閘門。

修改範圍：video-production SOP、能力與評審規則、評審雙檔樣板、通用 motion_project.py 的輸出狀態、現行文件入口及 A 修正版播放頁文字。能力紀錄一次說明目前不支援，不保留固定待辦欄位；抽幀、時序、音訊分析及使用者驗收繼續分開，不宣稱直接聽看通過。

歷史評審與 JSON 證據保留原樣，舊 assessment 的 continuous_av 不再轉入新 statuses。未重新編碼影片，未替舊評審更換來源指紋。兩側 Skill 已同步。

驗收：樣板無 AV 填位符與固定行；新 statuses 無 continuous_av，即使舊 assessment 含該欄位也不帶入；缺評審、過期來源及字幕等既有守門不放寬。現有 test_motion_project.py 測試執行結果於本輪收尾記錄。

實際結果：通用工具既有 7 項測試全部通過；Skill 結構診斷退出狀態 0；兩側實體副本同步檢查通過。
