## 1. 使用者回報的問題

使用 `plan-with-class-diagram` 為 `java-web-framework` 規劃 IoC 容器後，使用者無法只看類別圖就判斷：

1. 哪些類別原本不存在、本次要新增。
2. 哪些類別原本就存在、本次只修改內容（新增函數、修改既有行為或修改屬性），以及修改了哪些成員。
3. 本次要刪除哪些類別，以及刪除的類別是否應出現在圖上。

使用者要求在類別圖上直接標出新增、修改、刪除這三種狀態。

## 補充：施工後發現的根因 R3（2026-09-25）

- 使用者回報：在 Neovim 以 `<leader>cp` 預覽 `templates/class-diagram-proposal.example.md`，類別圖顯示「Syntax error in text / mermaid version 10.2.3」；在 VS Code 的 Markdown Preview Enhanced 中則正常顯示。
