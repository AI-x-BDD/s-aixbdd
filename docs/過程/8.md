## 3. 抽出共用解析入口並實作乘法

### 正式程式修改

在 `StringCalculator` 新增：

```java
private int[] parse(String numbers) {
    if (numbers.isEmpty()) {
        return new int[0];
    }
    return parseAndValidate(tokenize(numbers));
}
```

`add()` 改為呼叫 `parse(numbers)`，再由原有迴圈加總。空陣列不進入迴圈，因此仍回傳初始值 `0`。

新增乘法：

```java
public int multiply(String numbers) {
    int[] values = parse(numbers);
    if (values.length == 0) {
        return 0;
    }
    int product = 1;
    for (int value : values) {
        product *= value;
    }
    return product;
}
```

乘法先完成解析與驗證，再進行運算。空輸入明確回傳 `0`；非空輸入從乘法初始值 `1` 開始累乘。

`tokenize()` 與 `parseAndValidate()` 的內容沒有改動，沿用 Step 7 的規則與錯誤回報順序。

### 最終結構與責任

```text
StringCalculator
├── add(String)                 加總
├── multiply(String)            相乘，空輸入回傳 0
└── parse(String)               共用解析入口，空字串回傳空陣列
    ├── tokenize(String)        標頭驗證與 delimiter 切割
    └── parseAndValidate(...)   整數解析、缺值、格式、負數與錯誤收集
```

正式程式仍只有一個類別，利用 private 方法分開解析與運算。沒有新增 Parser、Validator、input model 或運算策略介面。

共用內容包括空輸入處理、數字切割、標頭解析、自訂 delimiter、整數解析、缺值與非法格式驗證、負數收集及錯誤訊息合併。沒有複製 parsing 或 validation；加法與乘法各保留一個簡單運算迴圈。
