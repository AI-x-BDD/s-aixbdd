# CH2 影片

目前為 113 秒、九幕的正式配音草稿，包含 SOP 解說與紅框。影片內容與美術仍可繼續調整。

| 目錄 | 用途 | 完成後處理 |
| --- | --- | --- |
| [製作來源](製作來源/) | 旁白、分鏡、圖稿、配音剪接設定與目前對齊資料 | 保留並版控 |
| [製作紀錄](製作紀錄/) | 敘事依據、製作流程、內容檢查、配音修訂及代表版本 | 保留並版控 |
| [素材](素材/) | 外部取得的原始配音、錄影與圖片 | 設定忽略；既有音檔待手動停止追蹤，詳見素材 README |

製作全流程見 [製作流程](製作紀錄/製作流程.md)，工具指令與重新對齊參數見 [videos 操作說明](../../../../videos/README.md)。

## 製作與預覽

從 repo 根目錄執行：

```sh
make -C videos setup
make -C videos check
make -C videos render
make -C videos preview
```

預覽：<http://127.0.0.1:60070/預覽/預覽.html>。

所有衍生檔都在 `videos/build/ch2-skill-engineering/`，不納入版控：

- `預覽/`：預覽網頁、時間軸、節奏檢查、生成的腳本與證據對照。
- `輸出/`：影片 MP4、SRT／VTT 字幕；上傳 YouTube 後可移除本地輸出。
- `中間產物/`：合成音訊、PNG、轉圖與分段編碼檔。

配音原檔只放 `素材/配音/`，稿件只放 `製作來源/配音/稿件/`；不要再混放。修改旁白以 `製作來源/內容/製作內容.json` 為準，同步稿件；音訊或內容改動後重新對齊，再 render。操作詳見 `videos/README.md`。

## 清理與後續章節規則

1. CH3、CH4 沿用「製作來源／製作紀錄／素材」分法，只建立實際需要的子目錄。
2. 素材、預覽與成品不自動刪除。影片交付並確認不再修改後，才手動清理。
3. 清理前記錄素材來源、取得方式及已發布影片連結；原始配音刪除後，重建需要重新取得音檔。重新生成的配音可能與原版不同，必須重新對齊。
4. 工具只讀取外層來源，環境、快取、衍生檔留在 videos；videos 可獨立複製，另指定外部來源。
5. 版本參考只保留刻意選定的代表版本，一般修改用 Git。刪除已追蹤素材不會刪除 Git 歷史，也不會消除既有歷史容量。
