# CH2 影片

目前基準為 B 深色配色＋M2 動態敘事：九幕、113 秒、原配音與燒錄字幕。最新進度見 [交付狀態](製作紀錄/設計/新流程測試/交付狀態.md)；技術檢查與使用者驗收分開記錄。

- [製作流程](製作紀錄/製作流程.md)：目前製作入口與歷史沿革。
- [通用 WORKFLOW](../../../../videos/WORKFLOW.md)：內容、分鏡、候選、製作與評審。
- [工具操作](../../../../videos/README.md)：預設 B 動態版的建置、字幕燒錄、稽核與預覽。
- [新流程紀錄](製作紀錄/設計/新流程測試/)：設計、逐幕分鏡、聲畫稽核與動態比較。

從 repo 根目錄執行 `make -C videos check test`、`make -C videos render`、`make -C videos preview`，開啟 <http://127.0.0.1:60071/預覽/交付.html>。不必另外執行 finish.py。所有衍生檔在 videos/build/ch2-workflow-test/；素材與來源不自動刪除。

製作來源、紀錄、素材分開保存。內容修改以 `製作來源/內容/製作內容.json` 為準並同步配音稿；音檔或內容改動須重新對齊。正式動態畫面為 `videos/motion/src/`（repo 根目錄起算）；`製作來源/畫面/新流程測試定版/` 保留固定構圖 B 焦點基準，舊 `畫面/圖稿/` 為歷史版。

CH3、CH4 沿用這三類目錄，需要時才新增子目錄。來源、設定與紀錄保留版控，原始素材及清理規則見 [素材說明](素材/README.md)。代表版本另存參考，一般修改使用 Git。
