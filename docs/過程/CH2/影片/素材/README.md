# clone 後需提供的原始素材

| 路徑 | 來源與用途 | 重新取得方式 |
| --- | --- | --- |
| 配音/完整.mp3 | 使用者以 ElevenLabs 產生的完整配音 | 從 ElevenLabs 歷史下載，或以完整旁白稿重新生成 |
| 配音/03-修正版.mp3 | 使用者補上 SOP 解說的第三段配音 | 從 ElevenLabs 歷史下載，或以 03.txt 重新生成 |

帳號、voice ID 與完整生成參數未提供，不能保證重新生成相同音檔。請在清理前確認 ElevenLabs 歷史仍可取得，或接受重新生成與對齊。

稿件在 `../製作來源/配音/稿件/`；剪接設定包含原檔 SHA-256，位於 `../製作來源/配音/剪接/`。新錄影與圖片依目的建立子目錄，不與配音混放。本目錄除本 README 外皆設定為忽略，現有本機原檔保留。兩份既有音檔尚被 Git 追蹤；停止追蹤操作被全域安全 hook 阻擋，需使用者手動移出 Git index 並提交後，才會從後續 clone 的工作目錄排除。clone 後請自行建立 `配音/` 並放入上述兩個同名原始檔。重建時會核對剪接設定內的 SHA-256，重新生成的同稿配音不能直接代用。

從 repo 根目錄核對：

```sh
shasum -a 256 docs/過程/CH2/影片/素材/配音/*.mp3
```

- `完整.mp3`：`7525e519e2450283e339b85d78488c94292520214d3fe917be4aa8944de67a4e`
- `03-修正版.mp3`：`1ea3ad95ae6b3ab0c4a4b2cbd21ce94ee0d3061b176f8d495bac9643417466c8`

只在取得原始檔後才能重建原版聲音；若原始檔已無法取得，必須重新配音、更新剪接設定並重新對齊。
