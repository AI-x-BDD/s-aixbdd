# 可清理的原始素材

| 路徑 | 來源與用途 | 重新取得方式 |
| --- | --- | --- |
| 配音/完整.mp3 | 使用者以 ElevenLabs 產生的完整配音 | 從 ElevenLabs 歷史下載，或以完整旁白稿重新生成 |
| 配音/03-修正版.mp3 | 使用者補上 SOP 解說的第三段配音 | 從 ElevenLabs 歷史下載，或以 03.txt 重新生成 |

帳號、voice ID 與完整生成參數未提供，不能保證重新生成相同音檔。請在清理前確認 ElevenLabs 歷史仍可取得，或接受重新生成與對齊。

稿件在 `../製作來源/配音/稿件/`；剪接設定包含原檔 SHA-256，位於 `../製作來源/配音/剪接/`。新錄影與圖片依目的建立子目錄，不與配音混放。影片交付前保留目前兩份音檔，交付並確認後可刪除素材，保留本 README。
