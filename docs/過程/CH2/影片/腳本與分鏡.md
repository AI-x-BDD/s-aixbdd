## 逐字旁白與分鏡

### 00:00:00 至 00:00:09 由下而上組合

這是我做出的 Skill Engineering。它把分工明確的小技能組合起來，用來新建 Skill，也用來優化既有 Skill。

畫面：六張主圖中的第一張。先看「8 支 primitives → 1 支 orchestrator → 3 支成果」，右側交代新建／優化兩種任務。

靜幀：[第 01 張](靜幀/01.svg)。

### 00:00:09 至 00:00:30 primitives 的分工

這套基礎技能分成兩組。Form 負責把關各個部位。Form Description 寫清楚各支技能的用途與使用時機；Form SOP 整理執行流程。規則要有正反例；樣板提供骨架和範例；腳本寫清楚輸入輸出。三支 Deriver，從流程步驟抽出部位，再接回流程。

畫面：上方 form-sop；下方 Rule／Template／Script 三欄，分別呈現 derive → form。依旁白點亮 Form 與三種部位的具體要求，再說明 Deriver，介紹 Form Description 的用途與使用時機。

靜幀：[第 02 張](靜幀/02.svg)。

### 00:00:30 至 00:01:07 Engineering 如何調度

收到任務，Engineering 先定義預期。優化時先找問題與根因，確認後再提藍圖。施工先用 Form SOP 整理流程。步驟需要規則、固定輸出或自動化，就交給對應的 Deriver。它呼叫 Form 建立檔案，也把讀取或執行時機接回流程，避免檔案建好了，流程卻沒有使用它。既有部位只改內容，就直接交給 Form。這三支優化主要走 SOP 和 Rule；Template 和 Script 依任務需要選用。最後完成檢查與驗收。

畫面：先呈現定義預期、優化才走的根因確認、藍圖確認；接著點亮 SOP，三條可選抽取路徑，再回到 SOP 載入／執行。末段顯示既有部位只改內容可直交 Form，以及本次主要走 SOP／Rule。

靜幀：[第 03 張](靜幀/03.svg)。

畫面：同版型前後卡：左側流程、分類與訊息規則混合；右側 SOP 與三份規則。

靜幀：[第 04 張](靜幀/04.svg)。
