目前工具可讀圖片、解碼影片並分析音訊資料；本對話沒有直接音訊輸入或連續影音理解工具。完整辨識與每秒抽幀不等於直接聽看，不判定聲音自然度、英文發音及連續觀看舒適度已通過。影片音軌與焦點時間的結構性檢查可以由 AI 執行；完整聲畫感受仍待人工聽看，或另行接入、實測並記錄能處理影音的服務。不能以瀏覽器開始播放代替 AI 的聽看證據。

## 成片核對與限制

`render` 自動呼叫 finish.py，完成字幕燒錄、來源雜湊、完整解碼及 `review.py --capture`。每段成片中點與尾端抽幀，入口在正式版的 `預覽/聲畫稽核/index.html`。成片產製時的來源指紋若過期，不能繼續抽幀評審；需重建。

核對表只驗證指定的焦點存在與持續時間；仍可能漏掉錯誤契約、其他物件搶焦點、細字、短暫遮擋及插值誤差。需檢視實際輸出，對疑點增加取樣，再獨立記錄視覺觀察與判斷。不是每個靜止段都要增加動畫：問題開場保留唯一大字及閱讀時間，有明確理由。

最新成片雜湊、實際觀察、命令結果與下一步見 `交付狀態.md`；完整基準與修訂比較在 build 稽核頁。未完成的聽感與連續觀看不標成通過。

最終修訂成片另外重跑能力實測：113 張、51 段、末段 112.72 秒，耗時 8.17 秒；成片 hash 與 `交付狀態.md` 一致。原版與修訂版的壓縮音訊流 hash 相同。98 張中點／尾端抽幀的總覽全部檢視，另以原尺寸查看的檔案及觀察列於交付狀態；仍不等同每影格或連續影音評審。
