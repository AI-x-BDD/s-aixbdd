# CH2 配色與結構適配補驗

2026-10-17。依已修訂流程續做；既有製作授權有效。本輪是方向確認前的候選補驗，不是正式成片驗收。

## 內容條件與取捨

來源是本片九幕旁白及 `設計依據.md`：觀眾需辨識 Engineering／Form／Deriver 的責任、三種案例規則如何分開、抽出規則後如何接回載入。來源沒有指定深綠、深紫、藍或赭黃。新舊、種類、先後主要由標籤、位置、分岔、索引及揭露承擔，顏色主要標示當下解說。

因此結構可由內容關係判斷；確切色相屬美術裁量。希望維持文件閱讀與工程圖解的表現，這是提案方向，不是普遍色彩心理結論。

## 推薦與實際候選

推薦 **C：A 的文件圖解結構＋中性底與文字＋單一藍色 focus**。結構推薦來自以上內容關係；中性底與藍的確切色相是比較後的美術裁量，沒有唯一正解，也未證明客觀勝過赭黃。原 A、B 均保留，不以未觀察到的缺陷淘汰。

C 全長 113.00 秒，1600×900、25fps，含音訊與字幕。另有 17.40 秒有聲代表片段（53.04–70.44）、九幕縮圖、36 個 MP4 狀態及 27 個過渡中點。合成音檔 SHA-256 與 A 一致：`90be7b63843854a480625dd6db6b8c89653acd6ecec9e66a10055df98c356b1a`。C 是隔離候選，未覆寫正式片。

## 分項評審與界線

- 色彩適配：完成本輪候選比較；選色依據、裁量與反例已分開。靜態評審未見已確認但未處理的內容衝突；觀眾實際感受仍待確認。
- 可讀性：C 七組基礎文字背景組合最低 4.82:1；所有語意狀態可見文字最低累積 opacity 為 0.85。次文字以 0.85 疊次背景的保守檢查為 4.57:1；accent 沒有非零淡化的靜止文字。數值不代表審美通過。
- 結構與 focus：主代理看過五套三幕圖、C 的 scene-02／04／05 全尺寸畫格、36 狀態及 27 過渡總覽。Claude Code 另以 Read 看過相同五套比較圖、三張 C 全尺寸畫格、狀態與過渡總覽，並核對 04 來源程式；未發現阻擋方向確認的問題。總覽小字未逐一全尺寸核對。
- 動態與聲音：全片解碼通過。雙方只看靜幀與過渡拼圖，沒有聽聲音或連續觀看動態；0.20 秒淡化有短暫疊字，Form 切 Deriver 最明顯，不能當作靜止狀態重疊或宣稱播放舒適度通過。保留為部分預覽的已知限制。
