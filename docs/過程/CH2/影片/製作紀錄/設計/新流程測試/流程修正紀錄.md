# 2026-10-17 內容適配流程修正

## 問題與責任界線

原流程已要求依內容設計配色與結構；原 Skill 的 P1、P3 主要規範色彩階層、角色及對比，並未提供完整色相選擇程序。個案實跑已有內容到結構的依據及修正，也已有色彩角色、對比和同構圖對照，但缺少色系選擇的比較判斷；主代理仍推薦整套 A 並要求使用者選版。這同時暴露執行與驗收失誤，以及流程未明訂比較證據與退回條件。不能歸因為未安裝、未讀 Skill，也不把所有結構工作一概判成沒做。

## 與 Claude Code 討論

透過 Herdr 的既有 `ch2-readme-review` 請 Claude Code 閱讀 WORKFLOW、editorial Skill 與三份個案紀錄，唯讀提出修正；再請其複查更新後流程並演練四個情境。

採納：分開判斷色彩與結構；追溯色彩任務及選色依據；同構圖對照仍需檢查明暗與色相的混合影響；檢查可能反例；技術可讀性不替代內容適配；證據缺漏退回；更正個案推薦與選版狀態。diff 紅綠慣例只記為待核對風險。

調整其建議：不把「先比明暗再比強調色」固定為每片唯一程序；依推薦主張控制變數。不把美術裁量全交使用者決定，AI 仍須比較並推薦、揭露取捨。不採納對主代理是否偷懶的推測，保留可核對的執行事實。
