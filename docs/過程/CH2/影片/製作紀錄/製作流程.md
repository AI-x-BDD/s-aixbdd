# CH2 影片製作流程

更新日期：2026-10-17。本文件記錄現行做法；早期版本的差異集中在文末「製作沿革」。工具指令與重新對齊參數以 [videos 操作說明](../../../../../videos/README.md) 為準。

## 目前狀態

目前為九幕、113.00 秒的正式配音草稿。已接入 ElevenLabs 完整配音及第三段修正版，補齊五支 Form 中的 SOP 解說與紅框。字幕、場景切換與紅框依實際語音詞時間定位，未額外加入補時靜音。

目錄搬移後已完整重建，來源、合成音檔及時間軸一致性檢查通過。這些技術檢查不等同完整逐句聽審或最終交付驗收。美術與視覺設計仍待後續調整。

## 從內容規劃到輸出的現行流程

1. **確認內容範圍。** 長度 90–120 秒，上限 120 秒；主軸為 Skill Engineering、primitives 的調度，以及 Conventional Commits、TBD、Double Diamond 三支技能的前後差異。三支差異須平衡呈現。
2. **整理依據與敘事。** 對照專案內 Skills 與前後比較文件，建立證據引用。使用問題式開場、分工圖、完整委派流程與一致的前後對照；方法及來源見 [敘事與參考](敘事與參考.md)。Description 屬整體分工，五支 Form 都要有說明及對應畫面。
3. **編寫旁白與分鏡。** 修改 `../製作來源/內容/製作內容.json` 的 scenes、visual、claims 與 focus，再同步 `../製作來源/配音/稿件/` 的完整及分段 TXT。確認旁白內容、圖中文字與焦點逐項對應，再交付配音。
4. **製作畫面。** 修改 `../製作來源/畫面/圖稿/` 的 SVG，保持目前 1600×900 規格。畫面支持當下旁白的重點，讓觀眾知道要看哪裡；維持已確認的緊湊節奏。
5. **取得正式配音。** 將核對過的稿件交由使用者在 ElevenLabs 生成，原檔放在 `../素材/配音/`。保留聲線與生成設定的已知資料；尚未提供的參數如實標明。系統語音只供未取得正式配音時預覽。
6. **依設定剪接配音。** 現行設定將原完整音檔 11.36–36.04 秒替換為第三段修正版，其餘保留且不變速。`make -C videos audio` 依剪接 JSON 及原檔雜湊重建合成音檔，寫入 build 中間產物。其他影片可直接設定完整音檔，無須套用這個替換方式。
7. **取得或更新對齊資料。** 音檔或內容 JSON 改動時，先重建音檔，再依工具說明執行本機 MLX Whisper 與原稿匹配，保存對齊 JSON。只搬移路徑且檔案內容未變時，沿用通過雜湊檢查的資料即可。字幕顯示原稿，辨識異字的時間可能採內插，仍需聽看核對。
8. **完整建置。** 先 check，再 render；工具依語音時間安排九幕切換、字幕與 focus，將 SVG 轉成 PNG，再編碼影片。原始素材與製作來源唯讀，所有生成檔都寫入 `videos/build/ch2-skill-engineering/`。
9. **驗證與人工檢查。** 檢查來源及對齊雜湊、片長、九幕連續性、字幕接續、五支 Form 的逐項旁白與紅框、靜音、預覽連結及 MP4 解碼；在瀏覽器聽看畫面切換、英文發音、字幕與紅框。核對結果見 [內容核對](內容核對.md)、[配音修訂](配音修訂.md)及 [目錄整理](目錄整理.md)。
10. **保存過程與交付。** 更新製作決策、修改原因及驗證結果，一般版本使用 Git。代表版本才另存參考快照。完成交付並確認不再修改後，依 [CH2 目錄規則](../README.md)手動清理素材與 build，留下來源、重建方式及發布連結。

## 重建與預覽

從 repo 根目錄執行：

```sh
make -C videos setup
make -C videos check
make -C videos render
UV_CACHE_DIR=videos/.cache/uv videos/.venv/bin/python videos/tests/check_recorded.py
make -C videos preview
```

上述命令適用於來源及配音未改動的重建。更換音檔或修改內容 JSON 時，先依 [重新對齊說明](../../../../../videos/README.md#配音剪接與對齊)處理，再執行 check／render。

預覽為 <http://127.0.0.1:60070/預覽/預覽.html>。伺服器已啟動時，render 後重新整理即可。當次是否正在執行須現查，不依賴先前 PID。

| 輸出位置 | 內容 |
| --- | --- |
| `videos/build/ch2-skill-engineering/預覽/` | 網頁、時間軸、節奏檢查、腳本與證據對照 |
| `videos/build/ch2-skill-engineering/輸出/` | 影片.mp4、SRT／VTT 字幕 |
| `videos/build/ch2-skill-engineering/中間產物/` | 合成音訊、PNG、轉圖及分段編碼 |
