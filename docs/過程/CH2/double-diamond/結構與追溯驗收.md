## 載入與消費

共通判準在所有用途載入；分流與需求分析依主題適用，跨用途不排斥。三份規則的 READ 位於同一 Phase、第一個 THINK 消費之前，中間只有其他 READ；各具名清單被分析、草稿與 CHECK 使用。案例按需形成案例參考，在分析步驟使用；不把案例升格成通用規範。

規則內容不在主檔重述。候選方案的數量及例外只由需求分析 Rule 3 定義，Rule 6 使用同一判斷；共通來源分類由判準 Rule 2 定義，其他規則只標示自身所屬層級。沒有跨檔循環引用。
