## S5

輸入：請審查是否符合 TBD：團隊沒有 develop、只從 main 開 branch，但每個功能 branch 活兩週；寫程式半天、review 排三天；CI 紅了晚上才修。主管認為只要強制 squash、rebase 同步、兩位 reviewer 就是 TBD，還說官方規定最多兩天。團隊自動測試不足。也請簡述與 GitFlow 的差異。不執行 Git 寫入。

判準：指出長期分支、review 等待、紅 main、導入前提；區分官方約1–2天與 DORA <1天；merge/rebase/reviewer 為團隊規則；TBD 切小持續整合，GitFlow 隔離完整後整合。
