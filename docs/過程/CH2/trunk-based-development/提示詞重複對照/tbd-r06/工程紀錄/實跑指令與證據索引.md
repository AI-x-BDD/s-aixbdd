## 副作用與可重現限制

前後副作用與同題檢查.json 逐題保存前後結束狀態與同題比對。暫存目錄不是完整應用程式 checkout，包含受測完整 Skill 與輸入；本次為唯讀規劃／審查任務，這項隔離可核對回答及檔案副作用，不驗證真實 Git、CI 或發布。底層模型參數未暴露，資源讀取與隱藏 CHECK 的觀察限制見修改後結果.md。臨時路徑可能被系統清除，輸入／版本／雜湊與原始回答已在 repo 紀錄保存，可重建環境，但不能保證重現相同隨機輸出。
