## 行為差異

配對基線及新版 S1–S3、S5–S8 七題皆通過原領域判準，無證據顯示領域行為改善。新版讀檔軌跡符合條件：規劃與審查讀兩 RuleFile，純比較僅共同檔。S4 結構另行通過。完整逐題評分與測試限制見 [修改後配對驗收結果.md](修改後配對驗收結果.md)。相同命令與預設設定已沿用，但精確模型、temperature、seed 無法核實，不宣稱完全受控。

既有蒐證前測與配對測試分開：初次 S1 的空格方向誤述、S2 的 review 適用範圍張力保留於原紀錄。配對舊版 S1 已正確描述缺少空格，故不能把新版若答對空格宣稱為 Skill 修正所致。

## 確認與限制

- 根因與第二版藍圖已分別取得明確確認；第一版未通過的依賴缺口及修正完整保留。
- 首次施工技能快照已在新版實跑前保存，不覆寫；回修若有發生，須另記版本與原因。
- 實跑方法、逐字輸入、讀檔工具事件、原始輸出、副作用與設定以配對測試紀錄為準；沒有取得的模型／內部設定不冒稱已控制。
- 未 commit、push；驗收完成才提供 commit message 草稿。
