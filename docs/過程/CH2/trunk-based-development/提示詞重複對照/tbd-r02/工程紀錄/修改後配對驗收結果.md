- 配對舊版與新版七題皆通過相同領域判準；沒有證據顯示領域答案改善。這次證實的是模組化結構及適用規則載入可達性，沒有宣稱修好未證實行為故障。

- 實際採 codex exec --ephemeral 全新 process，並非藍圖原擬 fork_turns=none 子代理；兩輪配對均採相同 CLI 方法。初次三題子代理蒐證另列，不混算為同環境配對。
- 相同模型設定未覆寫、相同命令繼承預設，但 CLI 事件沒有揭露精確後端模型、temperature、seed，故此條件無法完全核實。這是本次測試限制，不當作已滿足；若需嚴格證明相同精確模型設定，仍須外部提供可固定並可查核的測試資源。
