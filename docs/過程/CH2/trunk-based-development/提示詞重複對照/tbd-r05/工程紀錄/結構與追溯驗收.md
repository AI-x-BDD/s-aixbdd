| 案例與來源 | 案例檔 SHA-256 與基線相同，全部參考連結保留；通過 |
| 結構診斷 | 施工後 JSON 為 0 error、0 warning；通過 |
| 同步 | 規定同步與 --check 退出 0，輸出兩邊一致；無僅目標端存在 Skill 訊息；通過 |
