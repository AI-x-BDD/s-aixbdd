## 任務範圍與共通判斷

- 任務範圍：規劃 production 2.4 的金額計算 Hotfix、將修正同步到 `release/2.4`，並維持 `main` 的 2.5 開發可工作。
- TBD 核心：修正先整合到單一 trunk `main`，維持 `main` 可工作，再把已驗證修正帶到已發布版本；不在 `release/2.4` 另行修一份而漏回 `main`。
