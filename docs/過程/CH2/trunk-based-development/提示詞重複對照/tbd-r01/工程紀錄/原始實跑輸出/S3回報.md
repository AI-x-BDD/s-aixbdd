## Phase 1 判斷

任務範圍是：把四天的 UI／API／權限需求拆成可每日整合的短期 PR，並處理月底前不可曝光的限制。

共通判斷如下：

- TBD 的核心是不要讓程式碼分開太久；所有變更持續整合 `main`，且 `main` 每次合併後仍可工作、可發布。
- 四天工作要切成每個約一天內可完成並合併的小變更。每個小變更各開短期 branch，合併後刪除 branch；工作期間同步最新 `main`。
- 月底前不能曝光，所以使用預設關閉的 `reportExport` Feature Flag。部署和對使用者開放分開處理；穩定後刪除用完的 flag。
- 這個情境沒有大型重構或舊 API 相容性遷移的資料，因此目前不需要 Branch by Abstraction 或新舊並存。若實作時才發現需要替換既有匯出引擎或破壞既有 API，應重新評估相應技巧。
- branch 壽命要包含等 review 的時間。TBD 官方通常以 1～2 天描述短期 branch；DORA 以不到一天為目標，兩者都不是「兩天」的硬性門檻。

## Phase 2 最終規劃

所有 PR 都從最新 `main` 開自己的短期 branch，完成後依序執行 build → lint → unit test → 必要的 integration test，再送 PR review；CI green 且 review 通過才 merge，merge 後刪除 branch。`reportExport` 在月底前維持關閉。

PR 1：建立 `reportExport` Feature Flag（預設關閉）、報表匯出 API contract／client scaffolding 與測試，現有使用流程不改變 — 使用技巧：Feature Flag

PR 2：實作報表匯出 API 與必要的輸入／輸出驗證，路徑受 `reportExport` 控制並補 API 的 unit／integration tests — 使用技巧：Feature Flag

PR 3：加入報表匯出的權限能力與 API authorization tests；flag 關閉時不影響現有權限與既有 API — 使用技巧：Feature Flag

PR 4：加入 UI 匯出入口、狀態處理與 API 串接，入口受 `reportExport` 控制並補 UI／integration tests — 使用技巧：Feature Flag

PR 5：月底依實際授權名單或 rollout 規則開啟 `reportExport`，確認監控與回滾方式後逐步對使用者曝光 — 使用技巧：Feature Flag

PR 6：功能穩定後移除 `reportExport` 旗標與不再需要的分支程式碼，保留穩定後的正式路徑 — 使用技巧：Feature Flag

每個 PR merge 後 main 為什麼仍可工作：PR 1～4 的新路徑都在預設關閉的 `reportExport` 下，既有 UI、API 與權限流程維持原行為；每個 PR 都必須通過 CI 與 review。PR 5 是獨立的曝光變更，可依 rollout 結果回滾；PR 6 只在功能穩定後清理旗標。若 CI 讓 `main` 變紅，先修復或立即 revert，再停止繼續加入新功能。

預估 branch 壽命（含等 review）：每個實作 PR 目標為數小時至 1 個工作日內；PR 5、PR 6 也各自維持短期。若 review 使 branch 跨日，應檢查是否仍可切小或改善 review 阻礙；TBD 官方的 1～2 天是通常建議，DORA 的不到一天是更嚴格目標，不是絕對硬性規則。

## 送出前六題檢查

1. 能不能切到一天內可以 merge？可以；PR 1～4 分別拆成 flag／contract、API、權限、UI，PR 5／6 另行處理曝光與清理。
2. 這個 PR 現在 merge，`main` 還能正常工作嗎？可以；新路徑預設關閉，且每個 PR 需通過 CI 與 review。實際可行性仍需依未提供的專案架構驗證。
3. 未完成功能能不能用 Feature Flag 隱藏？可以；`reportExport` 預設關閉，月底才開啟。
4. 大改造能不能用 abstraction 讓新舊實作共存？目前沒有大改造資料，暫不適用；若涉及替換既有匯出引擎，再重新評估。
5. CI 能不能快速告訴我這次改動有沒有破壞系統？規劃要求每個 PR 執行 build、lint、unit test 與必要的 integration test；實際 CI 速度與設定未提供，不能宣稱已驗證。
6. 這個 branch 明天還會存在嗎？目標是不會；若因 review 跨日，需重新檢查拆分與 review 阻礙，不把跨日直接當成硬性違規。
