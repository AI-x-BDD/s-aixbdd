- 使用 collaboration.spawn_agent，fork_turns=none，不覆寫 model/reasoning_effort，繼承同一主代理模型與設定。模型自述 GPT-6；工具不提供精確部署版本、temperature、seed 或有效 reasoning effort，無法證明完全相同的內部採樣設定。
