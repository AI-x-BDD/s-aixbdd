共同整合規則：所有 branch 都從當時的 `main` 開出，合併前同步 `main`；每個 commit 觸發 build 與自動測試，CI 變紅立即修復或 revert，不讓 broken `main` 持續。branch 壽命估算包含等待 review。TBD 官方通常建議短期 branch 約 1～2 天；DORA 以少於 1 天為目標，兩者都不是硬性國際標準。branch 命名、squash／merge commit／rebase、reviewer 人數由團隊決定。
