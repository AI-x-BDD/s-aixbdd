# SOP

## Phase 1 -- 理解與設計

1. `READ` 使用者需求、目標 Skill 的 `SKILL.md`，以及待修改的既有骨架與範例（若有）。
2. `READ` 撰寫樣板組時，讀取 `rules/樣板組-格式規範.md` 的所有 Rule，建立樣板組完成檢查清單。
3. `THINK` 依已載入的樣板組完成檢查清單，確定產出檔案的格式、樣板名稱、固定結構、可替換內容與範例值；呼叫者提供已確認的設計（例如工程藍圖的工作項內容，或 skill-derive-* 的已確認提案）時，以該設計為內容，不另行設計，該設計不符合樣板組完成檢查清單時向呼叫者回報差異並停止。

完成條件：已確定符合樣板組完成檢查清單的目標路徑、內容結構及填位符號。

## Phase 2 -- 寫入與驗證

1. `WRITE` 依已載入的樣板組完成檢查清單，建立或更新骨架與範例兩個檔案。
2. `CHECK` 逐條驗證樣板組完成檢查清單，以及骨架與範例是否符合需求；未通過時修正後重新檢查。

完成條件：骨架與範例均已寫入，樣板組完成檢查清單及適用驗證均已通過。
