# 本片重建

需要本專案 videos 工具包、固定風格庫與 `.agents/skills/huashu-art-motion/` 固定上游；不需要舊退款成片。以下由 repo 根目錄執行；依賴採本片 workspace 的 package-lock.json。

```sh
videos/.venv/bin/python videos/scripts/style_library.py check --library videos/style-library \
  --selection videos/projects/refund-library-vox/style-selection.json
videos/.venv/bin/python videos/scripts/motion_project.py --config videos/projects/refund-library-vox/project.toml init
cp videos/projects/refund-library-vox/src/Root.tsx videos/build/refund-library-vox/workspace/motion/src/Root.tsx
cp videos/projects/refund-library-vox/src/index.ts videos/build/refund-library-vox/workspace/motion/src/index.ts
cp videos/projects/refund-library-vox/remotion.config.ts videos/build/refund-library-vox/workspace/motion/remotion.config.ts
videos/.venv/bin/python videos/scripts/motion_project.py --config videos/projects/refund-library-vox/project.toml prepare
PATH=/opt/homebrew/bin:/usr/bin:/bin videos/.venv/bin/python videos/scripts/motion_project.py --config videos/projects/refund-library-vox/project.toml render
videos/.venv/bin/python videos/scripts/motion_project.py --config videos/projects/refund-library-vox/project.toml review
```

## 修改畫面時

- 幾何、鏡頭、標記時間只改 `scene_state.py`，再執行 `/usr/bin/python3 videos/projects/refund-library-vox/scene_state.py` 重新產生 `materials/state.json`；不要直接手改 state。
- 旁白期望只改 `materials/focus.json`，依 `alignment.json` 的實際字元時間；不得從 state 的 active 複製。
- 繪圖程式改 `src/Root.tsx` 後複製進 workspace；prepare 會因來源指紋改變而重新綁定。

## 本機 runtime 設定

`remotion.config.ts` 以 `setBrowserExecutable` 指向 `/private/tmp/.remotion/chrome-headless-shell/mac-arm64/chrome-headless-shell-mac-arm64/chrome-headless-shell`：本次由複製而來的 workspace 瀏覽器無法載入 root component，改用同版 Remotion 新下載、已實測可渲染的 headless shell。這行只屬於這台機器；`/tmp` 被清除或換機時，刪除該行讓 Remotion 使用自身下載的瀏覽器，或改指向當機已驗證的同版 headless shell。修改後來源指紋改變，必須完整重新 prepare、render、review。

## 守門

重新輸出的影片必須重新查看實際編碼畫格並產生當次 assessment.json，再執行 `review --assessment <當次檔案>`；缺少評審時 review 會擋下，屬於預期守門。通過後才能 deliver，不可沿用本次舊評審冒充新檢查。現行成片 SHA 以 `videos/build/refund-library-vox/records/review.json` 與交付紀錄為準。
