# 本片重建

需要本專案 videos 工具包與固定風格庫，不需要舊退款成片。以下由 repo 根目錄執行；依賴採本片 package-lock.json。

```sh
videos/.venv/bin/python videos/scripts/motion_project.py --config videos/projects/refund-library-whiteboard/project.toml init
cp videos/projects/refund-library-whiteboard/src/Root.tsx videos/build/refund-library-whiteboard/workspace/motion/src/Root.tsx
cp videos/projects/refund-library-whiteboard/src/index.ts videos/build/refund-library-whiteboard/workspace/motion/src/index.ts
cp videos/projects/refund-library-whiteboard/remotion.config.ts videos/build/refund-library-whiteboard/workspace/motion/remotion.config.ts
npm ci --prefix videos/build/refund-library-whiteboard/workspace/motion
videos/.venv/bin/python videos/scripts/motion_project.py --config videos/projects/refund-library-whiteboard/project.toml prepare
PATH=/opt/homebrew/bin:/usr/bin:/bin videos/.venv/bin/python videos/scripts/motion_project.py --config videos/projects/refund-library-whiteboard/project.toml render
videos/.venv/bin/python videos/scripts/motion_project.py --config videos/projects/refund-library-whiteboard/project.toml review
```

重新輸出的影片必須重新查看實際編碼畫格並產生當次 assessment.json，再執行 `review --assessment <當次檔案>`。缺少評審時 review 會擋下，屬於預期守門。通過後才能 deliver，不可沿用本次舊評審冒充新檢查。

本次加速方式只共用既有鎖定 node_modules，不讀取舊成片或舊圖稿。若工作區的 node_modules 是連到本機既有套件的 symlink，重建可先移開該連結，再 npm ci；套件本身不得放進成果來源壓縮包。

本次原有渲染用瀏覽器出現載入逾時，已改用當次實測可輸出的 headless shell。remotion.config.ts 中的 /private/tmp 路徑屬本機 runtime，跨機器或暫存清理後需重新實測並更新，不能直接當成固定依賴。
