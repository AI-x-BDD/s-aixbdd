## 目錄與環境分工

s-aixbdd 的主體仍是 Skills。videos 有獨立環境，目前接受外層同一個 Git 管理；可複製出去，再指定 SOURCE_ROOT 讀取外部來源，素材不包含在工具內。CH3、CH4 延用章節下的「製作來源／製作紀錄／素材」分類。

一般建置使用 Python 標準函式庫及系統 FFmpeg／ffprobe、qlmanage；重新分析配音另需 alignment 選配依賴。系統預覽語音另用 macOS say。環境、模型與快取留在 videos 的忽略目錄，執行不依賴 temp。

check／render 會從兩份原始 MP3 依剪接設定重建合成配音；原始來源保持唯讀。預覽、輸出與中間產物都在 build 分目錄。完成交付後可依 [清理規則](../docs/過程/CH2/影片/README.md#清理與後續章節規則)清理素材及輸出，保存製作來源與紀錄。

## 影片內容必須延續的決定

- 90–120 秒，上限 120 秒；主軸是 Skill Engineering、primitives 調度與三支 Skill 的前後差異。
- 實作共五支 Form、三支 Deriver；Description 作為整體分工介紹，五支 Form 都要逐項說明並對應畫面。
- 用中性措辭介紹 Skill Engineering 的功能；不插入「額外增加 Description」沿革。
- 保留短句開場、旁白帶動切換與紅框引導，不加入多餘頁角標籤或補時停頓。
- 腳本分支用「可交給腳本自動處理」。三支技能差異維持平衡，不以 Conventional Commits 的個別修正或測試過程為主軸。

下一階段是美術與視覺方向：先比較代表畫面，再套用全片，保留已確認的敘事與節奏。
