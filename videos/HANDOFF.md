## 重建與驗證

從 repo 根目錄執行：

```sh
make -C videos render
videos/.venv/bin/python videos/tests/check_recorded.py
videos/.venv/bin/python videos/tests/check_visuals.py
make -C videos preview
```

已有伺服器時不必再啟動，重新整理預覽即可。當次服務狀態須現查。

SVG、語意狀態與詞時間先生成 PNG，再以固定四影格交叉淡化編碼；網頁不另畫聚焦效果。一般輸出為 1600×900、25fps；原始素材與來源在建置期間唯讀，所有衍生檔放 build。原始配音仍依 recipe 重建，不變速、不補時。

檢查涵蓋九幕狀態時間連續、五支 Form 完整、背景不遮字、缺少聚焦節點阻擋、過期對齊阻擋、MP4 全片解碼、畫格與瀏覽器播放。自動檢查不等於逐句聽審或使用者最終驗收。

## 必須延續的決定

- 主軸是 Engineering、八支 primitives（五 Form、三 Deriver）及三支 Skill 前後差異，長度 90–120 秒。
- Description 屬整體，不講額外增加；用中性措辭，不強調個人原創。
- 聚焦保留背景色塊，只移除左側色條；禁止文字被背景覆蓋。
- 不加頁角署名或道館標籤、不插入補時停頓、不以個別修正與測試沿革為主軸。
- videos 是可獨立複製的工具專案，從外層透過 SOURCE_ROOT 取得來源；不把素材搬進工具。
- 設計 Skill 安裝於 `videos/.agents/skills/`，來源記錄在該目錄的 `來源.json`；根目錄課程 Skills 未變動。

詳細操作及複製方式見 [README](README.md)，美術決策見 [美術提案](../docs/過程/CH2/影片/製作紀錄/美術提案.md)，過程見 [製作流程](../docs/過程/CH2/影片/製作紀錄/製作流程.md)。此 side conversation 無直接回填主對話的工具；主對話讀取本檔即可接續。Git 提交與遠端狀態需當次查詢。
